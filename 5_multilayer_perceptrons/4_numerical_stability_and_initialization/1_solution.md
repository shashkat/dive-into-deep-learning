- Another example of symmetry in neural networks could be from CNNs. If suppose we are trying to perform a convolution and converting a tensor with 1 channel into another tensor with y channels, then the kernel responsible to do the same will be of shape (1,y,k,k), where k is both the height and width of the kernel. If all the kernel weights are initialized with the same values across the second dimension (meaning that one kernel corresponding to one output channel can have different weight values, but all the other kernels have exactly same weights as this one), then all the y channels will have the same output, and effectively 'collapse' into a single channel. Hence, in such a case we would like that the different kernels store different weights to begin with, so that we don't end up storing the same feature map in all the channels of our image.
