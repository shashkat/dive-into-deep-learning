We just need to prove that for vectors $\vec{x}$ and $\vec{y}$, if $W\vec{x} = \vec{b}$ and $W\vec{y} = \vec{b}$, then $W\left(\lambda \vec{x}+\left(1-\lambda\right)\vec{y}\right)=\vec{b}$, which will prove that all the intermediate points in the set between any $\vec{x}$ and $\vec{y}$ will belong to the set because they satisfy the equation.

We can prove it as follows:

$W\left(\lambda \vec{x}+\left(1-\lambda\right)\vec{y}\right)$

= $\lambda W\vec{x}+\left(1-\lambda\right)W\vec{y}$

= $\lambda \vec{b}+\left(1-\lambda\right)\vec{b}$

= $\vec{b}$
