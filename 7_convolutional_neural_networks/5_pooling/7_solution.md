- Softmax takes in a vector and returns a vector, whose values are all positive and sum to 1. The main purpose of pooling operation is to reduce the dimensions of the image, and extract the important features only out of it. Hence, using plain softmax doesn't make sense. 
We can possibly do some averaging or maximum pooling after doing softmax operation, but it doesn't make much sense as in that case, the softmax operation doesn't serve any purpose. Averaging result would lose information from data compared to an averaging without softmax. Max pooling would give same result as max pooling without softmax.
