- So as far as I understand, gamma indicates how much we are weighing new data compared to old data while estimating gradient variation for the purpose of preconditioning. In general, if there is more gradient variation near the point where we are at in the hyperplane of the objective function for a particular direction, we want the learning rate in that direction to be slower because the gradient is in general more unpredictable, and we want to be careful in each step. 
Adjusting gamma as optimization progresses would be sensible if we have a reasonable idea about how the optimization function looks like with respect to gradient variation uniformity around the area we are at currently in the optimization. If the gradient variation is quite uniform where we are at, then we would like to keep a constantly high gamma so that we can make use of previous information more. If the gradient variation is quite non-uniform where we are at, then we would like to keep a lower gamma so that we trust new information more than previous information. 
Hence, we can possibly benefit from varying gamma every now and then, if we can somehow estimate how much uniformity there is in the variation of the gradient in the area we are currently at in the optimization function.
