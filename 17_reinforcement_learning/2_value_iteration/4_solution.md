- as long as gamma is between 0 and 1, noninclusive, the way we have implemented it (initializing value function for each state to be 0), it should take the same number of steps for value iteration to converge (finding the optimal route from each state). This is because even if the reward becomes closer to 0, with decreasing gamma, it still remains above 0, and hence from each state, out policy function ends up directing us to the correct next state. 
- If gamma is 0, no learning happens, because 2 states previous to the goal, there is no incentive of going in the right direction, as the reward is 0. 
- If gamma is 1, suboptimal routes are learnt (or nothing at all), because of the way frozen lake env works, as going outside board keeps us where we were, and hence, the model learns to just go out of board from the states with value function 1. Increase in the number of steps doesn't harm the value function of states, hence they don't try to learn the shortest/optimal route to goal.
