- We can implement a stride of 1/2 by having an intermediate convolution step between two steps which were there originally in a convolution of stride 1. To imagine how the computations would look like in the intermediate step, we can imagine simply the kernel overlapping with the image's pixels imperfectly (50% overlap). Hence, each pixel in the image will be multiplied with 0.5 times the kernel element/s that are half overlapping with it. Then, we will sum up all the multiplication terms to get the result for that position of the kernel. In this case, we will be increasing the size of the output image. This can be useful if we want to have a smoothing effect on the input image using the kernel.
